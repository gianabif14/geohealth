        Metodologi, Transparansi Simulasi & Privasi Lokasi

        1. Cakupan Wilayah Indonesia

        GeoHealth dirancang untuk menampilkan informasi fasilitas kesehatan dan titik panas di seluruh Indonesia. Peta memuat data hotspot sesuai area yang sedang terlihat (viewport) agar proses pemuatan lebih ringan. Batas administrasi kabupaten/kota ditampilkan ketika peta diperbesar ke tingkat zoom 7 atau lebih.

        2. Perhitungan Jarak dan Rute

        Pencarian fasilitas kesehatan terdekat dihitung menggunakan rumus Haversine dan geodesik ellipsoid WGS84 dalam satuan meter (bukan derajat atau proyeksi Web Mercator EPSG:3857). Arah kompas dihitung memakai azimuth balik geodesik (pyproj.Geod / ST_Azimuth). Rute jalan raya disediakan sebagai fitur opsional melalui layanan publik OSRM dengan cadangan garis lurus apabila kuota layanan sedang penuh.

        3. Transparansi Sumber Data & Simulasi

        Lokasi rumah sakit, puskesmas, dan klinik berasal dari data OpenStreetMap dan daftar terverifikasi di Indonesia (dapat ditambah melalui impor CSV di data/custom/). Karena data ketersediaan tempat tidur, stok oksigen, dan dokter jaga belum terhubung ke API real-time seluruh rumah sakit, nilai kapasitas tersebut dibangkitkan dengan generator deterministik dan selalu diberi label eksplisit Data simulasi beserta waktu pembaruannya.

        4. Batasan Data Titik Panas (Hotspot)

        Titik panas satelit (VIIRS/MODIS NASA FIRMS atau sampel berlabel) merupakan indikator anomali suhu permukaan sebagai konteks risiko wilayah, bukan bukti langsung kebakaran aktif ataupun kepekatan asap di permukaan tanah.

        5. Pelindungan Privasi Lokasi (UU PDP No. 27 Tahun 2022)

        • Cakupan validasi: titik koordinat yang dipakai untuk pencarian dibatasi pada wilayah Indonesia sesuai konfigurasi backend.
        • Minimisasi data: secara bawaan koordinat Anda dibulatkan ke 3 angka desimal (presisi sekitar 110 meter) sebelum dikirim ke server.
        • Tanpa penyimpanan jejak: server hanya menggunakan koordinat sebagai parameter kueri sesaat, menambahkan header Cache-Control: no-store, dan menyensor parameter koordinat dari state log.
        • Accuracy gating & Plausibility check: sistem memberi tahu Anda bila akurasi GPS perangkat lebih buruk dari 500 meter atau bila terdeteksi loncatan lokasi tidak wajar (> 140 km/jam).
